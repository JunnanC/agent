# identity 模块 Checklist

> 每一项通过运行代码或观察行为验证，聚焦系统行为与 spec 对齐。

## 实现完整性

- [ ] 六张表模型字段与 V4.0 一致且均为非托管模型。（验证：模型测试与 `rg --files apps/identity | rg migrations`）
- [ ] 登录、刷新、登出与当前用户接口可调用。（验证：认证 API 测试）
- [ ] 权限领域服务与 DRF 权限类可被调用。（验证：权限测试与 API 越权测试）
- [ ] 管理用户、权限矩阵与配额接口可调用。（验证：管理 API 测试）
- [ ] identity 未直接读写其他业务模块表。（验证：源码扫描无其他业务模型导入）

## 认证与令牌

- [ ] 正确账号密码登录返回令牌对与用户摘要。（验证：`POST /auth/login`）
- [ ] 错误密码与不存在账号返回一致错误信息。（验证：两次调用并断言响应一致）
- [ ] 禁用账号返回 `40302 ACCOUNT_DISABLED`。（验证：禁用夹具登录）
- [ ] 有效但未加入团队账号返回 `40303 MEMBERSHIP_REQUIRED`。（验证：无成员夹具登录）
- [ ] 刷新令牌成功轮换，旧刷新令牌立即失效。（验证：连续两次刷新）
- [ ] 重放已轮换刷新令牌触发该用户全部活动会话撤销。（验证：观察外部会话撤销事件）
- [ ] 登出后旧访问令牌立即失效。（验证：携带旧令牌调用受保护接口）
- [ ] 重复登出仍返回成功。（验证：同一令牌连续登出）
- [ ] 登出不影响工作区会话。（验证：外部工作区会话状态不变）
- [ ] `GET /auth/me` 忽略请求体中的伪造身份声明。（验证：传入其他 user_id 与 role）

## 权限与数据范围

- [ ] 四种内置角色权限矩阵逐条符合设计。（验证：矩阵化权限测试）
- [ ] 无权限动作返回 `403 FORBIDDEN`。（验证：角色 × 动作矩阵测试）
- [ ] 直接构造他人资源 ID 仍返回 `403 FORBIDDEN`。（验证：越权 API 测试）
- [ ] 前端隐藏入口不影响后端拒绝。（验证：绕过 UI 直接调用 API）
- [ ] 用户认证状态参与权限裁决。（验证：未认证用户夹具）
- [ ] 未认证且团队策略 `DENIED` 时实验启动动作被拒绝。（验证：mock membership 领域服务）
- [ ] 非系统管理员访问管理接口返回 `403 FORBIDDEN`。（验证：四种非管理员角色调用）

## 管理用户

- [ ] 用户列表分页默认 1 页 20 条，最大 100 条。（验证：分页 API 测试）
- [ ] 关键字、角色与状态筛选生效。（验证：构造数据后查询）
- [ ] `created_at/updated_at/username` 排序白名单生效，非法字段被拒绝。（验证：排序 API 测试）
- [ ] 手机号展示中间四位脱敏。（验证：响应断言）
- [ ] 软删除用户不出现在列表。（验证：软删除夹具）
- [ ] 单条创建返回 201 并初始化默认配额。（验证：创建后查询配额）
- [ ] username、email、phone 唯一性错误返回 `40901 STATE_CONFLICT`。（验证：重复创建）
- [ ] 非内置角色返回 `40003` 对应既有错误语义。（验证：伪造角色 ID）
- [ ] 批量导入返回 202、`operation_id`、`trace_id` 与 `PROCESSING`。（验证：批量导入 API）
- [ ] 重复提交同一批量请求不产生两批用户。（验证：同幂等键重放）
- [ ] CSV 缺列或格式错误返回 `42201 POLICY_REJECTED`。（验证：无效文件夹具）
- [ ] 禁用用户时发布会话与通知撤销事件。（验证：检查 Outbox）
- [ ] 禁用用户时自身账号被阻止。（验证：管理员禁用自身）
- [ ] 管理员降级自身被阻止。（验证：管理员修改自身角色）
- [ ] 状态与角色变更写入审计并记录前后值。（验证：查询审计表或 mock 审计）

## 权限矩阵与配额

- [ ] 权限矩阵返回四个内置角色、权限明细与统计。（验证：`GET /admin/permissions`）
- [ ] `role_code` 与 `resource` 筛选生效。（验证：矩阵 API 测试）
- [ ] 权限矩阵不可通过 API 修改。（验证：源码路由与只读方法检查）
- [ ] 配额查询返回所有上限与已用量。（验证：`GET /admin/user-quotas/{userId}`）
- [ ] 配额序列化层输出 C10 裁决后的接口别名。（验证：响应字段断言）
- [ ] 调整配额上限后立即生效。（验证：PATCH 后查询）
- [ ] 同一幂等键重复调用 `adjust_quota` 只生效一次。（验证：重复调用并比较用量）
- [ ] 并发扣减不能超过上限。（验证：多线程测试）
- [ ] 配额调整事务失败时事实、幂等标记与事件全部回滚。（验证：触发异常后检查）
- [ ] 配额保持 `used_x >= 0` 且 `used_x <= max_x`。（验证：边界测试）

## 安全与合规

- [ ] 密码使用不可逆强哈希存储。（验证：数据库字段测试）
- [ ] 刷新令牌仅存哈希，不存明文。（验证：模型测试）
- [ ] 日志、审计与响应不出现密码、Token、API 密钥。（验证：扫描测试输出并断言脱敏）
- [ ] 访问令牌包含 user_id、role_code、membership_status 与 jti。（验证：JWT 声明测试）
- [ ] 服务端只信任令牌解析结果。（验证：伪造请求归属字段）
- [ ] 所有写接口启用 common 幂等装饰器。（验证：源码检查与 API 测试）
- [ ] 所有写操作落审计。（验证：审计断言）
- [ ] 不新增 migration。（验证：文件扫描）

## 集成与质量

- [ ] identity 路由挂载到全局 URL。（验证：调用真实 API 路径）
- [ ] common 响应、错误码、分页、幂等、审计与 Outbox 均被复用。（验证：源码导入检查）
- [ ] 外部 membership、workspace、notification、file 服务通过接口或事件交互。（验证：mock 与 Outbox 测试）
- [ ] Django check 无错误。（验证：`manage.py check --settings=config.settings.test`）
- [ ] Ruff format 检查通过。（验证：`python -m ruff format --check apps/identity`）
- [ ] Ruff 静态检查通过。（验证：`python -m ruff check apps/identity`）
- [ ] identity 测试全部通过。（验证：`python -m pytest apps/identity -q`）
- [ ] identity 覆盖率不低于 80%。（验证：pytest coverage 输出）

## 端到端场景

- [ ] 场景一：系统管理员登录 → 创建用户 → 查询用户与配额 → 调整配额上限 → 审计可追溯。（验证：完整 API 流程）
- [ ] 场景二：普通用户登录 → 获取权限 → 直接构造他人资源 ID → 返回 403。（验证：完整越权流程）
- [ ] 场景三：用户刷新令牌 → 登出 → 旧令牌失效 → 重复登出成功。（验证：完整令牌生命周期）
- [ ] 场景四：管理员禁用用户 → 会话与通知撤销事件生成 → 用户访问立即失败。（验证：Outbox 与认证状态）
- [ ] 场景五：批量导入用户 → 重复提交同幂等键 → 回放受理响应且不重复创建。（验证：异步受理与幂等重放）
