# P03 courses 课程、任职与选课

## 目标

建立课程化业务主链路：课程、章节与资料、公告与日历、问答、负责人/助教、课程能力授权、选课周期、邀请/批量名册、容量、先修关系和课程复制。

## 后端范围

执行分为两个连续出口：P03-A 先完成课程、任职、grant、选课、容量和基础名册；P03-B 再完成内容、问答、邀请/导入、先修和课程复制。P03-B 必须复用已验收的 P03-A service，不建立旁路批量写入。

- 初始 schema：课程/任职/grant/选课事件，以及 chapter、material/material version、announcement、calendar event、question/answer、prerequisite、invitation、enrollment import job/item、course copy job。
- 课程草稿、发布、关闭、归档检查、负责人交接、助教任命和 grant 撤销。
- 章节使用显式发布/撤下动作；资料聚合下创建不可变版本并显式发布/撤下。实验、Agent 引用和历史页面固定指向 material version，已发布引用不被物理覆盖。
- OPEN/APPROVAL 选课、撤回、退课检查、退课、教师审批和移除。
- 邀请码只存摘要并受次数/时间/课程范围限制；批量名册先预检后执行，以 job/row/规范化身份逐行幂等。
- 课程/章节先修关系写入时校验同域引用和无环；只生成可解释的满足状态，不自动选课。
- 课程复制为异步 job；P03 先复制课程设置、章节、资料引用策略、公告/日历草稿和问答策略，并预留后续领域复制处理器。不复制名册、学生任务、报告、审核、Agent 会话或运行实例。
- 使用生成列/live 唯一约束防止同一课程学生出现两个 PENDING/ACTIVE 周期；容量操作锁定课程行。
- selector 按 portal、course staff、grant、本人 enrollment 裁剪；写 service 事务内再次校验。
- 课程事件写 Audit/Outbox；不在本阶段创建实验任务。

## 前端范围

- user-web：公开课程目录、课程详情、章节、资料、公告、日历、问答、申请/邀请选课、我的课程和退课阻断。
- teacher-web：课程列表、课程设置、内容编排、公告/日历/问答、课程复制、负责人交接、助教/grant、邀请码、名册导入和申请审批。
- admin-web：课程监管只读、合规冻结/解冻入口的 API 壳。

## 测试与验收

- 两名学生争最后容量只能一个 ACTIVE；两名教师审批最后名额只能一个成功。
- 同一学生重复选课只有一个 live enrollment；历史周期不覆盖旧事件。
- 助教无 grant 默认不可见；课程 A staff 不能读取课程 B 名册。
- 负责人交接保持恰一个有效 OWNER；撤销最后负责人被阻断。
- 退课/移除有活动任务时返回 blockers；写入时再次检查并审计。
- 先修关系成环、跨课程章节引用、未发布资料访问和越权问答处置稳定拒绝。
- 章节/资料未发布前学生不可见；已发布资料修改会产生新版本，旧实验和引用仍可按权限解析原版本。
- 批量导入重复执行不重复生成 live enrollment；逐行失败可重试且不回滚已成功行。
- 课程复制重试返回同一 job，目标课程不含任何学生业务数据。
- API 列表、详情、404 越权、ETag、幂等和 Outbox 测试通过。

## 不做

- 不创建实验任务、运行实例、报告或审核数据；模板内容在 P05 实现。
- 不把平台管理员自动视为课程教师，不支持班级/小组/多租户。
- 不实现 Moodle/Canvas/LTI 或其他 LMS 专用同步。

## 出口

课程可以从 DRAFT 到 PUBLISHED/CLOSED，教师可组织并复制课程内容、管理问答和批量名册，学生可按先修和容量产生可审计选课周期；P04 可在课程维度挂载治理配额。
