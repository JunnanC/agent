# P00 工程与基础设施基座

## 目标

建立可持续开发的后端、三端前端、无前端机器 API 入口、Nginx、API Gateway、Docker Swarm 和数据服务空环境；不实现业务模型。

## 前置与产物

- 上游：架构 `00`、`02`、`04`、`05`、`06`。
- 按架构总纲的目标版本创建 `backend/COMPATIBILITY.md` 和后端/前端依赖锁文件；提交后由锁文件成为实现基线。
- 产物：空 Django 项目、前端 workspace、初始容器镜像、环境变量清单、OpenAPI 导出命令、预发布 compose/stack 配置。

## 后端与 API

- 建立 `settings/{base,local,test,integration,prod}.py`、ASGI、Celery、URL 汇总和健康检查。
- 建立 `core/accounts/courses/governance/labtemplates/experiments/provisioning/workspaces/reports/reviews/archives/agents/notifications/analytics/integrations` AppConfig 和空目录。
- 固定 `/api/v2`、SSE `/api/v2/events/stream`、`/workspace`、`/files` 路径与统一 JSON 错误入口；不建立独立 `/events` API 前缀。
- 配置数据库连接、Redis、MinIO、MongoDB 日志连接、OTel/Prometheus 环境变量；密钥只从 Secrets/环境注入。

## 三端前端

- 建立 `apps/user-web`、`apps/teacher-web`、`apps/admin-web`，各自入口、路由、错误边界、构建配置。
- 建立 `packages/ui`、`api-client`、`auth-client`、`event-client`、`query-keys`、`config`。
- 只实现登录壳、健康页、403/404/500 和版本显示；不创建业务页面，不使用 Mock 推进业务状态。

## 入口与基础设施

- Nginx 配置三个网页 Host 和 `api.example.edu` 机器入口；后者无静态根目录，只开放 integration token/open API。配置 TLS、静态根目录、`/api/v2`、SSE、WebSocket 和 `/files` 代理。
- API Gateway 选定一种产品并配置路由、请求 ID、trace 透传、基础限流、超时和健康探针。
- 初始化 3 Manager 的 Swarm 预发布集群，设置 `edge/app/worker/runtime/data` 节点标签、Secrets、Configs、资源 reservation/limit 和滚动回滚。
- 启动空 MySQL、Redis、MongoDB Replica Set、MinIO、ClamAV；数据卷不依赖单节点临时目录。
- 每个节点部署 Fluent Bit/Vector/OTel Collector，先把 Nginx/Gateway/Django/Celery JSON stdout 写入 MongoDB `runtime_logs`。

## 测试与验收

- 三个 Host 能返回各自静态首页，伪造 `X-Portal` 会被覆盖或拒绝。
- `api.example.edu` 不返回网页，不接受 Portal Session，也不能访问 `/me`、`/teaching`、`/platform`；伪造 Integration 上下文被覆盖或拒绝。
- `/api/v2/health` 经 Nginx → Gateway → Django 返回 200；直接绕过网关不作为唯一测试。
- SSE 关闭代理 buffering，WebSocket Upgrade 可通过；上传大小和超时配置生效。
- 空 MySQL 可建立、清理并重复建立；Redis、MongoDB、MinIO 健康检查通过。
- 日志进入 MongoDB 且字段脱敏；MongoDB 暂不可用不阻塞健康接口。
- 三端 typecheck、lint、build 和最小 Playwright smoke 通过。

## 不做

- 不创建 `teams` app、旧角色、业务表、业务 API 或单 SPA 入口。
- 不导入旧数据，不建立双写或旧 API 兼容层。
- 不把 Docker Socket 挂载给 Django Web。

## 出口

空环境可重复启动，真实入口链路可验证，三端独立构建，且后续阶段有统一命令、Secrets、日志和测试基座。
