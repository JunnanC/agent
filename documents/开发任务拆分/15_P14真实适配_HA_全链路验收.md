# P14 Docker Swarm/VM 真实适配、HA 与全链路验收

## 目标

将 P07/P11 的 FakeRuntime 替换/补充为真实 Docker Swarm 与可选 Linux libvirt/KVM 适配，并完成生产级入口、数据服务、恢复和性能验收。

## 后端范围

- `DockerSwarmAdapter`：镜像 digest、service、reservation/limit、节点约束、网络隔离、健康探测、幂等创建/销毁、TTL、滚动更新/回滚。
- 可选 `LibvirtAdapter`：VM、卷、启动探测、工作区通道和 300 秒预算；VM 不依赖 Windows 本机，需 Linux/WSL2+KVM 环境。
- 真实运行时健康检查、Swarm service/task 与 MySQL instance 对账、孤儿回收和补偿。
- 按 P04 策略接入课程实验预热、Swarm 扩缩容、冷却、空闲回收和预算护栏；扩缩容失败不改变 MySQL 业务状态。
- MinIO 归档回读、digest 校验、版本控制和 retention 清理。
- Swarm 3 Manager quorum、节点标签、Secrets、Configs、网络和最小权限 adapter 账号。

## 基础设施范围

- Nginx → API Gateway → Django → Celery → Swarm/数据服务真实链路。
- MySQL 备份/binlog、Redis 重建、MongoDB Replica Set/TTL/归档、MinIO 对象清单和恢复演练。
- 连接池、健康检查、超时、限流、熔断、SSE buffering、WebSocket Upgrade、滚动发布和回滚。

## 前端范围

- 真实容器实验室、Notebook/WebIDE/Terminal/Preview 和可选 VM 通道。
- 真实 SSE 断线恢复、自动保存、报告、审核、归档、通知和错误 trace。
- 课程章节/资料/公告/日历/问答、名册导入、课程复制、延期、检查点/回放、Rubric/批注/相似度、分析与开放集成真实链路。
- 课程 Agent 知识源摄取、索引重建、带引用回答、无来源降级、评测门禁、工具审批、反馈和成本看板。
- user-web 1440/920/390；teacher/admin 至少 1440/920；复杂表格不溢出、不遮挡。

## 测试与验收

- 容器启动 P95 ≤120s，VM 启动 P95 ≤300s；50 并发实例、20 并发启动、100 在线用户。
- 回收指令后 P95 ≤5min 释放资源；task/instance/reservation 对账无孤儿。
- SSE P95 ≤2s，断线 5s 内续传且事件不重复/不丢失；自动保存确认 RPO ≤30s。
- MySQL RPO ≤24h/RTO ≤4h；对象和 MongoDB 日志抽样恢复 100%。
- Swarm 丢失一个 Manager 仍保持 quorum；服务更新失败自动回滚；数据节点故障有演练记录。
- 完成课程主链路、审批容量、退课阻断、到期回收、资格撤销、跨端隔离、Agent 审批和异常补偿 E2E。
- 课程复制重试、名册逐行幂等、先修阻断、延期并发、检查点恢复和 Rubric 审核 E2E 通过。
- Agent 跨课程/未发布资料检索拒绝，无可靠来源不伪造引用，profile 未过评测不能激活。
- 相似度、风险信号和推荐不会自动拒绝、扣分、退课、选课或改变任务状态。
- OIDC 登录/绑定恢复、开放 API scope/课程 grant、Webhook 签名/重放/退避/死信 E2E 通过。

## 不做

- 不通过放宽网络隔离、审批护栏、日志脱敏或权限来“方便演示”。
- 不用真实外部服务替代单元测试；真实适配器使用专门集成套件。
- 不在 P14 临时增加业务规则或补做前置阶段缺失功能。
- 不为验收临时增加 LMS 连接器、PWA、离线通知、独立移动端只读、国际化或专项无障碍范围。

## 出口

生产候选环境完成三端、统一后端、Swarm、MySQL、Redis、MongoDB、MinIO、日志、观测、恢复和 NFR 验收，才能进入发布评审。
