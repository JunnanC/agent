# 01 产品范围与需求基线

**版本：** v1.0  
**状态：** 待审核的候选开发基线

## 1. 产品定义

多Agent智能虚拟化实验平台是一套面向教学、训练和实验实践的 PC Web 云实验平台。教师基于已发布且不可变的模板版本创建任务并指定用户；平台自动创建容器或虚拟机环境；用户在浏览器工作区完成实验、保存过程并提交报告或成果；教师或评测服务审核；平台完成成果归档后撤销访问、销毁实例并释放配额。

产品的核心闭环为：

```text
用户申请加入/教师直接添加 -> 成员成为ACTIVE -> 教师模板/手册 -> 发布并指定ACTIVE用户 -> 自动装载容器或虚拟机
-> 实验保存 -> 报告或成果提交 -> 审核通过/退回
-> 最终归档 -> 撤销访问 -> 销毁实例和释放配额
```

平台不是模板市场、通用云主机控制台、在线刷题平台或无约束聊天工具。普通用户不需要安装本地运行时，也不能自行选择镜像、虚拟机模板、依赖、网络策略或资源规格。

## 2. 第一阶段目标

1. 跑通教师发布到归档销毁的完整闭环，并覆盖容器与虚拟机两类运行时。
2. 普通用户可申请加入和退出团队；ORG_ADMIN可审核、直接添加或移除成员。仅ACTIVE成员能进入分配给自己的任务，不能创建模板或自由创建环境。
3. 环境装载具备幂等创建、阶段进度、断线恢复、失败诊断、重试和取消能力。
4. 工作区按模板提供 WebIDE、Notebook、Web 终端、Web 预览或远程桌面，访问全部经过平台网关和短期会话。
5. 报告正文、附件、成果、日志和快照在临时实例销毁前完成平台侧持久化和校验。
6. Agent 在列表、装载、实验和报告阶段可达，且上下文、工具审批和审计均受控。
7. 在关键操作中落实固定 RBAC、数据范围、配额、幂等、Outbox、补偿和审计。

## 3. 需求优先级

| 优先级 | 功能范围 | 上线判断 |
|---|---|---|
| P0 | 登录、固定四角色、后端授权和数据范围 | 无法授权或存在越权即不可上线 |
| P0 | 团队成员资格、加入申请、退出、审核、直接添加和移除 | 非成员可获得新分配或启动；退出/移除绕过阻断或最后管理员保护即不可上线 |
| P0 | 模板版本、发布前预检、任务发布、指定用户和任务撤回 | 无法形成冻结任务或撤回不能收敛即不可上线 |
| P0 | Docker/OCI 容器与 libvirt/KVM 虚拟机适配 | 任一类型不能完成创建、访问、快照和销毁即不可上线 |
| P0 | 自动装载、进度、SSE 续传、幂等、重试和取消 | 重复建实例或失败不可恢复即不可上线 |
| P0 | 工作区网关、手册、起始资源、短期访问会话和过程保存 | 用户无法实验或凭据不可撤销即不可上线 |
| P0 | 报告/成果版本、附件、预览、审核、退回重提和通知 | 提交证据不可冻结或审核不闭环即不可上线 |
| P0 | 归档清单与摘要、导出、销毁、配额释放和补偿 | 归档与资源生命周期不闭环即不可上线 |
| P0 | Agent 基础入口、任务上下文、手册解释、错误诊断、审批和审计 | 入口不可达、越权读取或高风险操作绕过审批即不可上线 |
| P0 | 配额、审计、监控、Outbox 和异常实例人工处置 | 状态无法追踪或部分成功无法收敛即不可上线 |
| P1 | Agent 自动修复、复杂多Agent工作流和增强报告生成 | 不影响 P0 的受控辅助能力 |
| P1 | 更丰富的自动评测规则、教学分析和批量导出 | P0 可限定规则类型和导出规模 |
| P2 | 协作实验、模板市场、能力画像、多租户和私有化增强 | 不占用 P0 交付资源 |

## 4. 产品边界

### 4.1 第一阶段明确包含

- 固定角色：`SYSTEM_ADMIN`、`ORG_ADMIN`、`ORG_SUB_ADMIN`、`USER`。
- 单团队成员资格：账号、固定角色与成员资格分离；USER可申请加入/退出，ORG_ADMIN可审核、直接添加/移除，ORG_SUB_ADMIN默认无成员管理权限。
- 教师模板、不可变版本、容器/虚拟机环境预检、任务发布和用户分配。
- 用户任务列表、任务详情、自动装载、工作区、报告/成果、审核结果和归档详情。
- 容器的 WebIDE、Notebook、Web 终端；虚拟机的浏览器远程桌面或 Web 终端。
- Agent 悬浮控件及基础上下文辅助、审批和调用审计。
- 系统管理端的用户、固定角色、运行时、实例、配额、补偿、事件和审计能力。

### 4.2 第一阶段明确不包含

- 协作实验、模板交易或共享社区。
- 普通用户上传并运行任意镜像、编辑依赖或开放任意公网访问。
- AI 无审批自动执行高风险操作、全量自动修复或无限制模型调用。
- 自定义角色、自定义权限、组织/班级/课程/训练营等二级组织体系。
- 跨地域容灾、复杂多租户计费、移动端原生应用。

## 5. 关键业务规则

1. 教师只能发布已通过预检的模板版本；任务发布后固定引用该版本，不能原地修改。
2. 账号、固定角色和成员资格分离；成员状态为`PENDING`、`ACTIVE`、`REJECTED`、`EXITED`、`REMOVED`。仅`ACTIVE`成员可接收新分配，任务发布与启动均须重新校验。
3. 实例只能由有效的 `experiment_task_assignment` 触发；未发布、未分配、成员非ACTIVE、已撤回或不在时间窗口内均拒绝启动。
4. 退出或移除必须阻断未完成任务、活动实例及待审核/归档/销毁流程；成功后撤销活动工作区会话。最后一名有效`ORG_ADMIN`不可退出或被移除，需由`SYSTEM_ADMIN`完成交接。
5. `start`、`report/submit`、无报告成果提交、任务发布、成员变更、审核结论、归档触发和销毁链路按接口规范执行幂等保护。
6. `report_required=true` 时必须提交报告；`false` 时用户结束实验会生成包含快照、日志、结果和产物清单的系统成果版本，不能直接跳过审核。
7. 人工、自动和复合审核最终都产生唯一、可审计的结论；退回必须产生新可编辑版本，历史版本只读。
8. 只有归档状态为 `COMPLETED` 且清单 SHA-256 校验通过，才可撤销访问并销毁实例。
9. 访问凭据短期有效，只保存 JTI 摘要；实例停止、任务撤回、成员资格失效或进入销毁时立即撤销活动会话。
10. Agent 只能访问当前授权任务、实例、手册、文件和日志；写删文件、安装依赖、联网和高风险命令均进入策略审批与审计。
11. 任务状态与通知/异步事件使用 Outbox 保证原子性；运行时部分成功使用补偿任务最终收敛。成员历史及任务、报告、归档、审计记录不物理删除。

## 6. 首期非功能验收基线

下列数值是第一阶段测试环境和 UAT 的最低验收值，调整必须走需求变更流程：

| 类别 | 基线指标 |
|---|---|
| 容量 | 100 名并发在线用户、50 个并发运行实例、20 个并发环境启动请求 |
| API | 排除文件传输和运行时长任务后，读接口 P95 ≤ 500 ms，普通写接口 P95 ≤ 800 ms |
| 环境启动 | 已缓存镜像条件下容器就绪 P95 ≤ 120 秒；预热虚拟机模板条件下虚拟机就绪 P95 ≤ 300 秒 |
| 事件 | 状态事件产生后 P95 ≤ 2 秒到达；断线后 5 秒内开始续传，不丢失、不重复展示事件 |
| 保存 | 报告和工作区自动保存间隔 ≤ 10 秒；已确认保存内容的 RPO ≤ 30 秒 |
| 回收 | 收到销毁指令后 P95 ≤ 5 分钟释放运行时资源；失败必须进入补偿或人工处置 |
| 可用性 | UAT 连续 7 天核心 API 可用性 ≥ 99.5%，计划维护时间除外 |
| 恢复 | 关系数据库 RPO ≤ 24 小时、RTO ≤ 4 小时；归档抽样恢复成功率 100% |
| 存储 | 首期对象存储可用容量不少于 1 TB，容量达到 70%/85% 时分级告警，始终保留 15% 安全余量 |
| 兼容性 | Chrome、Edge 最近两个主版本；1440 px 桌面为主验收，920 px 和 390 px 不出现主体横向溢出 |

## 7. 身份、审核与保留默认值

- 账号密码登录为 P0；学校/企业认证资料可提交和审核。未认证账号默认不能启动实验，可由 `SYSTEM_ADMIN` 配置为只读或允许进入。
- 报告默认必交；默认审核模式为人工，任务可选择自动或复合审核。
- 报告/成果归档默认保留 365 天，审计日志默认保留 180 天，运行日志默认保留 30 天；教师可在系统上限内延长，不能缩短法定或审计保留期。
- 审核通过后立即触发归档；归档校验完成后 10 分钟内触发访问撤销和实例销毁。

## 8. 页面原型收敛规则

前端原型用于确认页面信息架构、状态反馈和操作步骤，不直接定义权限或服务端事实。普通用户端只可从“我的实验任务”启动已分配任务；不得上线自由创建环境、智能环境识别、自定义镜像/依赖/资源、未分配实验大厅或跨任务工作区切换入口。

审核通过、实例销毁、导出完成等终态必须来自审核、编排或归档服务，不能由浏览器定时器、前端内存状态或占位下载代替。系统运营端的用户、资源、Agent、模型、实例、安全、题库和审计页面属于 P0 治理界面，其写操作均须经过权限、二次确认、幂等和审计。页面明细和验收以 `附件3`（UI 设计文档 v1.0）与 `02` §8/PRD §6 为准（原 `11_页面原型驱动补充需求.md` 已停用，2026-09-17）。
