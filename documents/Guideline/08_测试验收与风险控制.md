# 08 测试验收与风险控制

**版本：** v1.0  
**状态：** 待审核的候选开发基线

## 1. P0 业务验收场景

| 编号 | 场景 | 通过标准 |
|---|---|---|
| AC-01 | 登录和权限 | 四角色路由正确；`USER` 页面和直接 API 均无模板写入、发布、运行时配置和他人数据权限 |
| AC-01A | 团队加入与成员状态 | 未加入USER可提交申请且重复PENDING幂等；ORG_ADMIN可审核通过/拒绝或按账号直接添加；ORG_SUB_ADMIN成员接口被拒绝；仅ACTIVE成员可被新分配或启动 |
| AC-01B | 团队退出与教师移除 | USER退出、ORG_ADMIN移除均二次确认并检查未完成任务、活动实例、审核/归档/销毁流程；阻断清单可见；成功后会话撤销、通知、审计和历史保留；最后有效ORG_ADMIN受保护 |
| AC-02 | 模板预检与任务发布 | 只能选择已发布版本；预检失败不可发布；指定用户、时间、报告和销毁策略一次性固化；重复发布不重复分配/通知 |
| AC-03 | 任务撤回 | 撤回禁止新启动；装载/运行实例按策略保存、撤销、回收；已审核/归档记录保留且有通知和审计 |
| AC-04 | 容器自动装载 | 按冻结模板完成镜像、材料、依赖、健康检查和短期凭据；重复点击只产生一个实例 |
| AC-05 | 虚拟机自动装载 | 完成白名单模板、Cloud-init、系统盘、远程桌面/Web 终端、快照和销毁；启动时间和失败路径符合指标 |
| AC-06 | 装载进度与恢复 | 阶段、步骤、耗时、百分比、失败原因、`retryable` 和 `trace_id` 可见；SSE 断线用 `Last-Event-ID` 续传且不重复；可断点重试/取消 |
| AC-07 | 工作区和会话 | 手册、起始模板、结果区和正确工作区可用；WebIDE/Notebook/终端或远程桌面按模板展示；会话到期/撤回不可继续访问 |
| AC-08 | 工作区和报告保存 | 工作内容和报告自动保存 ≤10 秒；断线恢复；报告草稿、附件、预览、版本历史和 ETag 冲突均可验证 |
| AC-09 | 报告/成果提交 | 必交任务冻结报告版本、附件、快照、日志和产物；非必交任务生成系统成果 manifest；重复提交幂等，不可伪造证据 |
| AC-10 | 审核和退回 | 人工、自动、复合三种模式至少各有一条用例；通过/退回唯一且可审计；退回产生新版本，历史不可覆盖；并发审核返回冲突 |
| AC-11 | Agent 可控性 | 列表、装载、工作区、报告均可通过鼠标/键盘打开；上下文只含授权对象；高风险安装/写删/联网/命令必须审批并记录调用 |
| AC-12 | 通知 | 发布、装载失败、提交、审核、归档、销毁和撤回通知可读/已读；跳转前鉴权，目标失效不泄露信息 |
| AC-13 | 归档 | 通过版本、附件、快照、日志、评测、产物全部进入归档；manifest 和文件 SHA-256 校验通过；归档未完成不能销毁 |
| AC-14 | 销毁和配额 | 先撤销会话，再停止/删除容器或虚拟机，最后释放配额；重复销毁、运行时已删数据库失败和补偿最大次数均能收敛/转人工 |
| AC-15 | 审计与 Outbox | 可按 assignment/instance/trace 查询完整时间线；业务事务与 Outbox 原子；消费者去重；日志不含明文凭据 |

## 2. 测试分层

- **单元测试：** 状态迁移、角色/数据范围、配额、报告版本、审核模式、策略、manifest 摘要和适配器错误。
- **集成测试：** Django/MySQL 事务、行锁、Redis 幂等、MinIO 元数据、Celery、Outbox、通知、补偿和审计。
- **契约测试：** OpenAPI、JSON Schema、Mock Server、TypeScript 客户端、错误码、ETag/revision 和 SSE 事件。
- **端到端测试：** 用户申请加入或教师直接添加 -> 成员ACTIVE -> 教师模板预检/发布 -> 指定ACTIVE用户 -> 容器/虚拟机装载 -> 工作区保存 -> 报告/成果 -> 审核 -> 归档 -> 销毁。
- **安全测试：** 越权/IDOR、令牌过期与撤销、文件上传、命令注入、网络白名单、容器隔离、虚拟机接入、Agent 工具审批和日志脱敏。
- **稳定性测试：** 20 个并发启动请求、重复回调、队列积压、SSE 断线、服务重启、对象存储暂不可用、运行时超时和补偿重入。
- **性能测试：** 按产品基线验证 API P95、双运行时启动、事件延迟、保存 RPO、回收 P95和 50 实例容量。
- **恢复演练：** MySQL RPO/RTO、MinIO 版本和归档抽样恢复、运行时部分成功、Outbox 重放和销毁中断后的状态收敛。
- **前端验收：** Chrome/Edge 最近两个版本、1440/920/390 px、键盘焦点、屏幕阅读器名称、Agent 避让和无横向溢出。
- **页面原型回归：** 以 `附件3`（UI 设计文档 v1.0）与 `02` §8/PRD §6 为页面验收依据，覆盖各页面状态与交互口径（原 `PUI-AC-01` 至 `PUI-AC-08` 随章节 11 停用，2026-09-17）；验证页面显示的任务、步骤、审核和销毁状态来自真实接口或事件，而非前端演示数据和计时器。

## 3. 风险与控制

| 风险 | 早期信号 | 控制措施 | 负责人 |
|---|---|---|---|
| 双运行时延期 | 单个运行时负责人积压、VM Adapter 无真实冒烟或启动超时 | 后端 3 按 RuntimeAdapter/容器/虚拟机顺序交付；M4-A 独立门禁，测试运维提前准备 libvirt 环境 | 后端 3、测试运维 |
| 范围膨胀 | P1/P2 需求绕过评审进入开发 | 需求追踪矩阵、变更评审、P0 资源锁定 | 项目经理 |
| 数据丢失 | 草稿只在临时盘、归档清单缺项 | 对象存储持久化、自动保存、manifest 校验、销毁前置检查 | 后端 2/测试运维 |
| 越权或凭据泄露 | ID 枚举、会话未撤销、日志出现令牌 | 服务端数据范围、短期 JTI、密钥扫描、权限回归 | 后端 1/测试运维 |
| 成员资格绕过或无法退出 | 非成员获得分配、成员失效仍能启动/访问，退出/移除无阻断或最后管理员丢失 | M1 ACTIVE资格服务、行锁/事务、会话撤销事件、成员状态与管理员保护回归 | 后端 1、后端 2、测试运维 |
| Agent 误操作 | 工具越权、上下文含其他任务、无审批 | 最小权限、策略审批、上下文白名单、调用审计和预算限额 | 后端 1 |
| 异步最终不一致 | Outbox 堵塞、补偿无限重试、配额负数 | event_id 去重、指数退避、最大次数、MANUAL队列、对账任务 | 后端 1/2 |
| 前端联调延期 | 接口字段临时变化、页面状态缺失 | G1 OpenAPI/Mock、契约 CI、M7/M8 顺序切片 | 后端（按域切片）、项目经理 |
| 原型与正式规则漂移 | USER 仍能看到自由创建环境或审核自动跳转为通过 | 以 PUI 收敛表审查路由、按钮、接口和 E2E；上线前移除或隔离演示 Mock | 后端 1/2/3（按域切片）、测试运维 |
| 性能不足 | P95 超标、队列积压、资源泄漏 | k6 压测、限流、容量告警、运行时配额和降级 | 测试运维、后端 3 |

## 4. 上线阻断条件

- 存在用户可创建未分配实例、查看他人任务、绕过审核或访问已撤销工作区的路径。
- 存在非ACTIVE成员获得新任务分配、启动已分配实验、签发工作区会话，或退出/移除可绕过阻断、审计、会话撤销和最后管理员保护的路径。
- 容器或虚拟机任一 P0 运行时无法完成创建、访问、快照、销毁和失败收敛。
- 重复启动、回调、提交或补偿会产生多个实例、重复扣配额、覆盖版本或销毁唯一成果。
- 归档摘要和文件校验未完成却进入销毁，或归档/销毁失败没有补偿/人工入口。
- Outbox/通知/SSE 无法去重和续传；关键动作无法通过业务 ID 和 trace 查询。
- 报告附件、预览、冲突保存、非必交成果、任务撤回或 Agent 高风险审批未通过。
- 未达到并发、启动、回收、可用性、RPO/RTO和存储安全余量基线。
- 安全、备份恢复、虚拟机隔离或销毁故障恢复演练未完成。
- 正式 USER 端仍可自由创建环境、查看未分配任务、切换冻结运行时，或页面终态与服务端任务状态不一致。
