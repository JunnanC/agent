# 05 接口设计与集成规范

**版本：** v1.0  
**状态：** 待审核的候选开发基线  
**契约：** OpenAPI 3.0，统一前缀 `/api/v1`

## 1. 通用约定

- JSON 使用 UTF-8；文件上传/下载使用受控预签名 URL，业务 API 只返回短期、绑定用户和资源的地址。
- 身份认证使用短期访问令牌和可轮换刷新令牌；服务端从令牌解析用户，不信任客户端 `user_id`、`role`、`assignment_id` 的归属声明。
- 幂等键适用于所有会改变事实或触发外部动作的接口：成员申请、审核、直接添加、退出、移除、任务发布、启动/取消、报告保存/提交、成果提交、审核、提前结束、归档、会话撤销、销毁和补偿重试。GET/HEAD/OPTIONS 不要求。服务端至少保留 24 小时，重放返回原 HTTP 状态和响应体，键与请求摘要不一致返回 `IDEMPOTENCY_CONFLICT`。
- 每个响应携带 `request_id`；异步操作返回 `operation_id` 和 `trace_id`。错误响应不泄露内部地址、凭据、SQL、堆栈或他人资源是否存在。
- 列表统一返回 `data.items`、`page`、`page_size`、`total`、`request_id`；排序和过滤字段白名单化。
- 写操作支持 `If-Match`/`ETag` 或显式 `revision`；并发冲突返回 409，不覆盖服务端较新版本。

## 2. 用户端接口

| 方法 | 路径 | 作用 | 关键规则 |
|---|---|---|---|
| GET | `/me/team-membership` | 当前成员资格与阻断摘要 | 返回状态、申请/处理时间、处理说明和退出阻断事项 |
| POST | `/me/team-membership/applications` | 提交加入申请 | 未加入才可申请；重复PENDING返回当前申请；使用`Idempotency-Key` |
| POST | `/me/team-membership/exit` | 主动退出团队 | 仅ACTIVE成员；检查未完成任务、活动实例、审核/归档/销毁流程；成功撤销会话 |
| GET | `/me/experiment-tasks` | 本人实验列表 | 只返回已发布、已分配且当前成员为ACTIVE的任务；支持名称/类型/难度/状态筛选 |
| GET | `/me/experiment-tasks/{assignmentId}` | 详情、手册摘要、环境摘要和状态 | 校验归属、成员资格、时间和任务状态 |
| POST | `/me/experiment-tasks/{assignmentId}/start` | 幂等启动/恢复装载 | 返回 202 和 `operation_id`；重新校验ACTIVE成员资格，禁止重复实例 |
| POST | `/me/experiment-tasks/{assignmentId}/provisioning/retry` | 从可恢复步骤重试 | 仅 `retryable=true` 且状态允许 |
| POST | `/me/experiment-tasks/{assignmentId}/provisioning/cancel` | 取消装载 | 二次确认；释放已锁定配额并进入取消收敛 |
| GET | `/me/experiment-tasks/{assignmentId}/provisioning` | 阶段、步骤、耗时、失败和重试 | 返回 `failure_stage`、`retryable`、`trace_id` |
| GET | `/me/experiment-tasks/{assignmentId}/events` | SSE 阶段事件 | 支持 `Last-Event-ID`；断线后续传和去重 |
| POST | `/me/experiment-tasks/{assignmentId}/workspace-sessions` | 签发短期工作区会话 | 只能选择模板允许的 `access_mode` |
| DELETE | `/me/experiment-tasks/{assignmentId}/workspace-sessions/{id}` | 撤销本人会话 | 记录审计；实例销毁时批量撤销 |
| GET | `/me/experiment-tasks/{assignmentId}/materials` | 手册、起始模板、数据集和附件 | 返回受控下载地址和只读属性 |
| GET | `/me/experiment-tasks/{assignmentId}/report` | 当前报告和修订号 | 没有报告时初始化草稿 |
| PUT | `/me/experiment-tasks/{assignmentId}/report/draft` | 保存当前草稿 | `revision`/`If-Match`；自动保存与手动保存同一语义，不创建提交版本 |
| GET | `/me/experiment-tasks/{assignmentId}/report/versions` | 版本历史 | 历史版本只读 |
| POST | `/me/experiment-tasks/{assignmentId}/report/attachments` | 上传报告附件 | 类型/大小/病毒扫描和进度；返回文件 ID |
| DELETE | `/me/experiment-tasks/{assignmentId}/report/attachments/{fileId}` | 删除未提交草稿附件 | 提交后禁止删除 |
| GET | `/me/experiment-tasks/{assignmentId}/report/preview` | 报告和附件清单预览 | 只读、按当前版本生成 |
| POST | `/me/experiment-tasks/{assignmentId}/report/submit` | 冻结并提交报告版本 | 必交字段/附件校验；返回 202 |
| POST | `/me/experiment-tasks/{assignmentId}/artifact/submit` | 非必交任务提交系统成果 | 编排服务生成 manifest，不接受用户伪造快照 |
| GET | `/me/experiment-tasks/{assignmentId}/review` | 审核结论、证据和退回原因 | 仅本人任务 |
| POST | `/me/experiment-tasks/{assignmentId}/finish` | 提前结束实验 | 保存草稿/快照后按报告策略进入审核，不直接完成 |
| GET | `/me/experiment-tasks/{assignmentId}/archive` | 归档详情、时间线和销毁状态 | 仅归档完成的对象可导出 |
| GET | `/me/experiment-tasks/{assignmentId}/archive/export` | 导出本人最终成果 | 短期下载地址，记录审计 |
| GET | `/me/notifications` | 通知列表 | 支持未读筛选和分页 |
| POST | `/me/notifications/{id}/read` | 标记已读 | 跳转前重新鉴权资源 |
| POST | `/me/agent/conversations` | 创建/恢复当前任务 Agent 会话 | 必须绑定任务和授权上下文 |
| POST | `/me/agent/conversations/{id}/messages` | 发送 Agent 消息/请求工具 | 高风险工具返回审批状态，不直接执行 |
| POST | `/me/agent/tool-approvals/{id}/approve` | 用户确认高风险工具 | 仅批准当前上下文、一次性操作 |

## 5. 异步事件载荷

`start`、提交、审核后归档、`finish`、撤回和销毁均返回 202（纯本地校验失败返回 4xx）。事件至少包含：

```json
{
  "event_id": "uuid",
  "event_type": "PROVISIONING_STEP_UPDATED",
  "occurred_at": "ISO-8601",
  "assignment_id": 1,
  "instance_id": 2,
  "operation_id": "uuid",
  "stage": "HEALTH_CHECK",
  "status": "RUNNING",
  "progress_percent": 60,
  "message": "脱敏后的用户提示",
  "retryable": false,
  "trace_id": "trace"
}
```

事件必须先写 `outbox_events` 后发布；SSE 按 `event_id` 去重，客户端按 `Last-Event-ID` 续传。SSE 不可用时以 provisioning/archive/instance 查询接口轮询，轮询不改变业务状态。

## 6. 错误规范

| HTTP | 错误码 | 场景 |
|---:|---|---|
| 400 | `VALIDATION_ERROR` | 参数、必填字段或状态迁移错误 |
| 401 | `UNAUTHENTICATED` | 未登录、令牌无效或过期 |
| 403 | `FORBIDDEN` | 角色、数据范围或策略拒绝 |
| 403 | `MEMBERSHIP_REQUIRED` / `MEMBERSHIP_PENDING` | 尚未加入或申请未生效，拒绝分配、启动或成员受限操作 |
| 404 | `RESOURCE_NOT_FOUND` | 不存在或当前用户不可见 |
| 409 | `STATE_CONFLICT` / `IDEMPOTENCY_CONFLICT` / `REVISION_CONFLICT` | 状态、幂等键或并发修订冲突 |
| 409 | `MEMBERSHIP_CHANGE_BLOCKED` / `LAST_TEAM_ADMIN_PROTECTED` | 退出或移除受未完成业务、活动实例或最后管理员保护阻断 |
| 413 | `FILE_TOO_LARGE` | 附件超过任务/系统上限 |
| 422 | `POLICY_REJECTED` / `QUOTA_EXCEEDED` / `PRECHECK_FAILED` | 策略、配额或发布前检查失败 |
| 429 | `RATE_LIMITED` | API、文件或 Agent 调用限流 |
| 503 | `RUNTIME_UNAVAILABLE` / `DEPENDENCY_UNAVAILABLE` | 运行时、队列、存储或工作区不可用 |

## 7. 契约冻结和联调规则

- G1 生成 OpenAPI 文件、Mock Server、错误码字典、事件 JSON Schema 和 TypeScript 客户端类型。
- 未登记字段、隐式状态、前端自行拼接路径和后端返回动态未约定字段均不得用于联调。
- API 变更必须说明兼容性、数据库迁移、UI 影响、测试用例和追踪矩阵变更；破坏性变更须升级版本或提供兼容窗口。
